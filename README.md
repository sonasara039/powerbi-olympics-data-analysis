# Olympics Data Analysis & Visualization | Power BI

## 📌 Project Overview

An interactive Power BI dashboard developed to analyze Olympic Games data and explore medal trends across countries, sports, gender, age groups, seasons, and athletes.

The dashboard transforms raw Olympic data into interactive visualizations and KPIs to provide insights into historical Olympic performance.

## 🎯 Objectives

* Analyze Olympic medal trends
* Compare medal performance across countries
* Explore medal distribution by sport
* Analyze participation and performance by gender
* Examine athlete age patterns
* Compare Summer and Winter Olympics
* Identify top-performing athletes and countries

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Modeling
* Data Cleaning & Transformation
* Interactive Visualizations
* KPI Cards

## 📊 Dashboard Features

* Total medals and KPI metrics
* Country-wise medal analysis
* Sport-wise medal distribution
* Gender-based analysis
* Age-based analysis
* Summer vs Winter Olympics comparison
* Top-performing athletes
* Interactive filters and slicers
* Trend visualizations

## 🔍 Key Analysis

The dashboard allows users to interactively explore Olympic medal patterns and compare performance across countries, sports, genders, seasons, and athletes.
